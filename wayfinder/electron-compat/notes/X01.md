# X01 — conformance-oracle-harness

_Research unit of the Electron compatibility wayfinder map; generated 2026-10-06; labels [fact]/[inference]/[unknown] as written by the unit agent; two independent refuters (invariants, Electron semantics) reviewed every decision._

## Summary

Design: a two-arm differential harness shaped like KEL-77 (Rust test owns and reaps each arm; hard failure when a binary is missing; exact arm revision in every record). Arm A (recorder) runs Keld-owned fixture apps under the pinned npm electron@44.4.5 binary (dist shasum 0be094f8e783febba75d591106f5c61c1e511b70; tag v44.4.5 -> commit 694f45852a0f1726cd23bfd379854de489cccb65) and emits a line-oriented transcript (seq, process, event, canonical args, monotonic delta). Arm B (replayer) runs the SAME unmodified fixture files with `electron` resolved to @keld/electron (today: tsconfig paths + `bun` child spawned by crates/keld-compat/tests/electron_lifecycle.rs against keld_core::LifecycleSession; TARGET: `keld dev --headless --smoke`, which is reserved/not live). A Rust comparator in keld-compat normalizes declared nondeterministic fields, diffs ordered sequences, and emits one keld.compat.evidence/v1 record per cell. The golden transcript is evidence-of-record, not the oracle: per AGENTS.md and KEL-77 §4.1 the oracle is the pinned Electron doc sentence (blob at commit 694f4585); a cell with no doc sentence can reach BEHAVIOR_MATCH only. Ladder: BEHAVIOR_MATCH (Keld transcript == golden under normalizers, >=1 OS, legacy_sandbox_off) -> CONFORMANCE_PASS (cited doc sentence + Keld-owned test independent of the diff + named negative control + pass on all 3 OS lanes, or explicit intentional_divergence ▲) -> CORPUS_VERIFIED (same observable matched in a real corpus app run through migrate+dev smoke on both arms, panel:product once a product corpus id is committed, authority profile strict_bun or visibly labeled legacy). Reuse: KEL-237's exact-bytes rule (denominator.corpus_sha256 == sha256 of committed manifest bytes, with mutation negative control) closes research 214's "canonical bytes UNPROVEN"; KEL-77 §4.3 digest for the fixture-set artifact.sha256; KEL-74 score() for all percentages. Placement: fixtures in packages/@keld/electron/fixtures/<family>/ (plain ESM JS runnable in both arms), goldens/manifest/denominator/evidence/receipts in crates/keld-compat/fixtures/<corpus-id>/ mirroring lifecycle-corpus, comparator tests in crates/keld-compat/tests/, corpus apps (draw.io, Zettlr) in the separate corpus repo (arch 04 §6). CI: PR lane = replay only on the existing 3-OS matrix (deterministic, no Electron download); weekly lane = recorder drift re-run at the same pin (Linux via xvfb-run as Electron's own CI does) + corpus-app smoke; regression P1 = `CI required` fails when any committed cell flips pass->fail/unknown or expected-fail->pass, with no retries, skips, or isCI gating (research 214 Table 4). Electron docs are silent on several order/error details (ready-to-show vs did-finish-load, duplicate ipcMain.handle, invoke no-handler text); those are recorded as observed-only cells, not conformance claims.

## Decisions (with refuter verdicts)

### X01-A1 — What is the oracle: the recorded Electron 44.4.5 golden transcript, or the pinned Electron documentation sentence?

**Proposed answer:** The pinned doc sentence (blob at commit 694f45852a0f1726cd23bfd379854de489cccb65) is the oracle for any CONFORMANCE_PASS cell; the golden transcript is immutable evidence-of-record that makes BEHAVIOR_MATCH falsifiable and exposes undocumented order/timing. A cell whose behavior the docs do not state (e.g. ready-to-show vs did-finish-load order) is tagged `observed-only` and can never exceed BEHAVIOR_MATCH; it is reported as a lead, not a compatibility claim. Owner: keld-compat comparator; boundary: manifest cell {operation_id, oracle_id, doc_blob_oid, doc_sentence_sha256, golden_sha256, normalizers[], negative_control}; failure mode: a transcript diff passing while the documented contract is violated (mirror oracle); observable contract: deleting the doc-cited Keld test or inverting the asserted sentence fails the cell independently of the transcript diff; first falsifier: a cell with a golden but no doc_blob_oid that is scored CONFORMANCE_PASS.

**Evidence:**
- AGENTS.md crates/keld-compat: 'Electron documented behavior = oracle. Conformance entry (citing doc/fixture) before implementation' [fact]
- docs/specs/kel77-bun-child-process-differential.md §4.1: 'Rejected: using the Node arm's live output as the oracle — a mirror, not an oracle: it cannot distinguish Bun is wrong from Node changed' [fact]
- .agents/testing.md: every test MUST use an independent oracle; reimplementing the algorithm is not independent [fact]
- research 214 Table 3: selection must be fixed before results ('Tests that pass cannot define N after results exist') [fact]

**Rejected alternatives:** (a) Golden transcript as sole oracle — mirror oracle; cannot tell Electron drift/flake from Keld defect; rejected by KEL-77 §4.1 precedent. (b) Electron spec/ tree as oracle — REFUSED by research 214. (c) Doc sentences only, no recorder — cannot falsify ordering/timing/destroyed-object details that docs omit, and gives no denominator-backed evidence of what 44.4.5 actually does.

**Confidence:** high · **Type:** grilling · **Unknowns:** How many Tier-1 observables have no doc sentence (observed-only share) is unmeasured until the recorder runs once; the docs are silent on duplicate ipcMain.handle error text, invoke no-handler text, ERR_ABORTED on superseded load, and ready-to-show/did-finish-load order.
