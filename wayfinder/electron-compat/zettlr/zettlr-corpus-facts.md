## Preload shape (the Zettlr-class contextBridge problem)

- `ipc` = unfiltered pass-through: `send(channel,...)`, `sendSync(event,...)`, `invoke(channel,...)`,
  `on(channel, listener) → () => ipcRenderer.off(...)` (a **function returned synchronously**).
- `config.get(key)` / `config.set(key, val)` → `ipcRenderer.sendSync('config-provider', …)` (**sync value**).
- `getCitationCallback(database)` → returns a function that calls `ipcRenderer.sendSync('citeproc-provider', …)`.
- `process` = platform, version, versions, arch, `uptime()`, **`getSystemVersion: process.getSystemVersion()` evaluated at preload load**, `env` copy, argv.
- `getPathForFile(file)` → `webUtils.getPathForFile`, `''` → `undefined`, throw → `undefined`.
- `pinia/config.ts` also calls `window.config`'s `sendSync` directly (`retrieveConfig()` re-run with a 50 ms throttle on every `config-provider` update push).

## Real application workflow (source paths)

1. **Launch.** `main.ts`: `handleExitArguments()` → `app.requestSingleInstanceLock()` else `app.exit(0)` → optional `--data-dir` → `app.whenReady().then(bootApplication)`. `bootApplication` (lifecycle.ts 38-100): `environmentCheck()` (spawns `quarto`/`git`/`pandoc --version`, `isTraySupported()`) → `new AppServiceContainer()` (constructors incl. the AppearanceProvider `subscribeNotification`) → `registerCustomProtocols` (`protocol.handle('safe-file')`) → `attachAppNavigationHandlers` (`app.on('web-contents-created')`: `setWindowOpenHandler → deny`, `will-navigate → preventDefault + shell.openExternal/openPath`, dev-server exception) → `appServiceContainer.boot()` in order Log, CSS, Config (onboarding window on first start or new version, `sandbox:false`), splash after 1 s (`sandbox:false`), FSAL (chokidar watchdog), RecentDocs, Assets, Stats, Appearance, Dictionary, `fsal.reindexFiles`, Target, Link, Search, **Command before Window**, Tag, Tray (only if `system.leaveAppRunning`), Citeproc, DocumentManager, Menu, Update (`net.online` gate), LRT → `windows.maybeShowWindows()` → `createMainWindow` (`webPreferences: { sandbox: true, preload }`, `show:false`, `loadURL(<webpack entry>?window_id=…)`, shown on `ready-to-show`; packaged entry is `file://…/.webpack/renderer/<name>/index.html`, dev is `http://localhost:3000/<name>`).
2. **Open.** Menu → `commands.run('root-open-files')` → `dialog.showOpenDialog` (async) → FSAL root; file-manager click → `invoke('documents-provider', {command:'open-file'})` → `ipcMain.handle('documents-provider')` → `fs.readFile` (utf8, BOM/linefeed normalised) → editor `invoke('documents-authority', {command:'get-document'})` returns the **whole text**; `syncWatchedFilePaths()` adds the path to the chokidar watcher.
3. **Edit.** CodeMirror collab: every `docChanged` → `invoke('documents-authority', {command:'push-updates'})` (re-push 100 ms later if more accrued) → main applies the `ChangeSet`, bumps version, `broadcastIpcMessage('documents-update')` to all windows, `BrowserWindow.setDocumentEdited(true)`; autosave default `'off'` (`'delayed'` 5000 ms, else 500 ms). Pull side long-polls via `ipcRenderer.on('documents-update')` + `invoke('pull-updates')`.
4. **Save.** Cmd+S menu item (`accelerator: 'Cmd+S'`, non-role click handler) → `focusedWindow.webContents.send('shortcut','save-file')` → renderer `invoke('documents-provider', {command:'save-file'})` → `saveFile` → `fs.writeFile` (BOM + original linefeed restored) → `FILE_SAVED` broadcast; error → `dialog.showErrorBox` + rethrow.
5. **Unsaved close.** Window `close`: `event.preventDefault()` → `askUserToCloseWindow` → **async** `dialog.showMessageBox(win, {buttons:[Yes,No,Cancel], defaultId:0, cancelId:2})` → `window.close()` again on allow; `createMainWindow`'s own `close` listener calls `webContents.session.clearStorageData({storages:['cookies','localstorage','shadercache']})`. Cmd+Q: `before-quit` → `preventDefault` → async `showMessageBox` (Save/Discard/Cancel) → `app.quit()` re-entered; `will-quit` → `preventDefault`, `await shutdownApplication()` (chokidar `close()`), `canQuit = true`, `app.quit()` again. No `showMessageBoxSync`, no `beforeunload`, no `executeJavaScript` anywhere.
