Does the compatibility-matrix cell state machine encode the maturity ladder honestly?

One cell of the Electron compatibility matrix is one observable of one Electron member, for example the order before-quit → window close → will-quit for app.quit(). This page runs the cell's state machine so you can check whether each step up the ladder UNSUPPORTED → SCAFFOLDED (L0) → PARTIAL (L1) → BEHAVIOR_MATCH → CONFORMANCE_PASS → CORPUS_VERIFIED can only be reached with the evidence it names, whether losing a gate demotes the cell and raises a P1, and whether ▲ accepted divergences, ✘ never, waivers and percentages behave the way the map and the live KEL-74 scorer say.

Logic prototype for wayfinder map gyldlab/keld#391 (units X01, F05, F06). Nothing here is implemented in Keld. The reducer lives in its own script block with no DOM access; the page only calls into it. Every button is always enabled: an action the real system would refuse returns its typed error instead of succeeding. Error codes marked live are quoted from the Keld repository at b4b907c3; codes marked proposed do not exist yet and are placeholders for the X01 spec.
