# ROADMAP ↔ Linear Phase Mapping

Linear projects use different phase numbers than `ROADMAP.md`. Use this table when
linking issues to roadmap milestones.

| Linear project | ROADMAP equivalent |
|----------------|-------------------|
| Phase 0 — Research & Competitive Analysis | Pre-foundation research (`docs/research/`) |
| Phase 1 — Architecture & Specs | Spec/RFC work (`docs/architecture/`) |
| Phase 2 — Foundation Scaffolding | ROADMAP Phase 0 Foundation + start of Phase 1 Window |
| *(not projectized yet)* | ROADMAP Phase 1 "Window on screen" — after Phase 2 scaffolding completes |

ROADMAP phases 2–4 (guard plane, ship, compat depth) are not yet projectized in Linear.
